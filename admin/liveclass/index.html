Publishing flow
1. Create and schedule the class.

2. The class is saved in Firestore as SCHEDULED.

3. Click START LIVE when the class begins.

4. Students see LIVE NOW in their Live Classes page.

5. Click END CLASS after the session finishes.
All three options use the same `liveClasses` collection. The Zoom API is not called when creating a class.
