Organize the lesson, choose its source, set a schedule and optionally attach an MCQ test.

YouTube links and direct MP4/HLS URLs are supported. For direct upload, choose Firebase Storage upload below.

Choose an image to upload through the configured secure ImgBB endpoint.
You can also paste an existing image URL.
ImgBB upload requires a server-side endpoint configured with your ImgBB API key. This page deliberately does not expose the private API key in browser code. Configure /api/upload-thumbnail to return {"url":"https://…"}.
