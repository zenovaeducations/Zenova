Real-life Applications of Trigonometry

ತ್ರಿಕೋನಮಿತಿಯ ನೈಜ ಜೀವನದ ಅನ್ವಯಗಳು

Trigonometry helps us find heights, distances and measurements that are difficult to measure directly.

ನೇರವಾಗಿ ಅಳೆಯಲು ಕಷ್ಟವಾದ ಎತ್ತರ, ದೂರ ಹಾಗೂ ಇತರ ಅಳತೆಗಳನ್ನು ಕಂಡುಹಿಡಿಯಲು ತ್ರಿಕೋನಮಿತಿ ಸಹಾಯ ಮಾಡುತ್ತದೆ.

1

Height of a tall structure

ಎತ್ತರವಾದ ಕಟ್ಟಡದ ಎತ್ತರ ಕಂಡುಹಿಡಿಯುವುದು

Find the height of a building, tower or tree without measuring it directly.

ಕಟ್ಟಡ, ಗೋಪುರ ಅಥವಾ ಮರದ ಎತ್ತರವನ್ನು ನೇರವಾಗಿ ಅಳೆಯದೆ ಕಂಡುಹಿಡಿಯಬಹುದು.

2

Width of a river

ನದಿಯ ಅಗಲವನ್ನು ಕಂಡುಹಿಡಿಯುವುದು

Find the width of a river or lake without crossing it.

ನದಿಯನ್ನು ದಾಟದೆ ಅದರ ಅಗಲವನ್ನು ಕಂಡುಹಿಡಿಯಬಹುದು.

3

Height of an aeroplane / balloon

ವಿಮಾನ ಅಥವಾ ಬಲೂನಿನ ಎತ್ತರ ಕಂಡುಹಿಡಿಯುವುದು

Find the height of an aeroplane, balloon or an object in the sky.

ವಿಮಾನ, ಗಾಳಿ ಬಲೂನ್ ಅಥವಾ ಆಕಾಶದಲ್ಲಿರುವ ವಸ್ತುವಿನ ಎತ್ತರವನ್ನು ಕಂಡುಹಿಡಿಯಬಹುದು.

Reciprocal Relationships

ವ್ಯುತ್ಕ್ರಮ ಸಂಬಂಧಗಳು

Three trigonometric ratios are the reciprocals of sine, cosine and tangent respectively.

ಮೂರು ತ್ರಿಕೋನಮಿತಿಯ ಅನುಪಾತಗಳು ಕ್ರಮವಾಗಿ ಸೈನ್, ಕೋಸೈನ್ ಮತ್ತು ಟ್ಯಾಂಜೆಂಟ್‌ಗಳ ವ್ಯುತ್ಕ್ರಮಗಳಾಗಿವೆ.

1. Cosecant

ಕೋಸೆಕಂಟ್ (cosec θ)
cosec θ = 1 / sin θ
Hypotenuse / Opposite side

ಕರ್ಣ / ಎದುರು ಬಾಹು

2. Secant

ಸೆಕಂಟ್ (sec θ)
sec θ = 1 / cos θ
Hypotenuse / Adjacent side

ಕರ್ಣ / ಪಕ್ಕದ ಬಾಹು

3. Cotangent

ಕೋಟ್ಯಾಂಜೆಂಟ್ (cot θ)
cot θ = 1 / tan θ
Adjacent side / Opposite side

ಪಕ್ಕದ ಬಾಹು / ಎದುರು ಬಾಹು
Remember: Each of these is the reciprocal of its corresponding ratio. ನೆನಪಿಡಿ: ಇವುಗಳಲ್ಲಿ ಪ್ರತಿಯೊಂದೂ ತನ್ನ ಅನುಗುಣವಾದ ಅನುಪಾತದ ವ್ಯುತ್ಕ್ರಮವಾಗಿದೆ.

Equal Angles & Trigonometric Expressions

ಸಮ ಸೈನ್ ಮೌಲ್ಯಗಳು ಮತ್ತು ತ್ರಿಕೋನಮಿತಿಯ ಅಭಿವ್ಯಕ್ತಿಗಳು

EXAMPLE 2 — PROOF

If ∠B and ∠Q are acute angles such that sin B = sin Q, prove that ∠B = ∠Q.
Given / ನೀಡಿರುವುದು
sin B = sin Q
Using the definitions:
AC / AB = PR / PQ
AC / PR = AB / PQ = k
By Pythagoras theorem, the third corresponding sides are also proportional:
BC / QR = k
Therefore, by SSS similarity criterion: ΔACB ~ ΔPRQ
∠B = ∠Q ✓
ಎರಡು ತೀಕ್ಷ್ಣ ಕೋನಗಳ ಸೈನ್ ಮೌಲ್ಯಗಳು ಸಮವಾಗಿದ್ದರೆ, ಕೋನಗಳೂ ಸಮವಾಗಿರುತ್ತವೆ.

EXAMPLE 3 — EVALUATION

In ΔACB, right-angled at C, AB = 29 units, BC = 21 units and ∠ABC = θ. Find:
(i) cos²θ + sin²θ
(ii) cos²θ − sin²θ
First, find AC using Pythagoras:
AC = √(29² − 21²)
= √(841 − 441) = 20
sin θ = 20/29
cos θ = 21/29
Substitute the values:
(i) (21/29)² + (20/29)² = 1
(ii) (21/29)² − (20/29)²
= (441 − 400)/841 = 41/841
Answers: (i) 1   |   (ii) 41/841

Verification & Finding Sides

ಸಮೀಕರಣದ ಪರಿಶೀಲನೆ ಮತ್ತು ಬಾಹುಗಳ ಉದ್ದ ಕಂಡುಹಿಡಿಯುವುದು

EXAMPLE 4 — VERIFICATION

In a right triangle ABC, right-angled at B, if tan A = 1, verify that:
2 sin A cos A = 1
Given / ನೀಡಿರುವುದು
tan A = BC / AB = 1
Therefore, BC = AB = k
By Pythagoras theorem:
AC = √(k² + k²) = k√2
Find the ratios:
sin A = 1/√2
cos A = 1/√2
Substitute into the expression:
2 sin A cos A
= 2 × 1/√2 × 1/√2
= 1 ✓ VERIFIED
ಕೊಟ್ಟಿರುವ ಸಮೀಕರಣವು ಸರಿ ಎಂದು ಪರಿಶೀಲಿಸಲಾಗಿದೆ.

EXAMPLE 5 — FINDING SIDES

In ΔOPQ, right-angled at P, OP = 7 cm and OQ − PQ = 1 cm. Find sin Q and cos Q.
Let PQ = x. Then OQ = x + 1.
By Pythagoras theorem:
OQ² = OP² + PQ²
(x + 1)² = 7² + x²
x² + 2x + 1 = 49 + x²
2x = 48
x = 24
Therefore, the sides are:
PQ = 24 cm
OQ = 25 cm
OP = 7 cm
sin Q = 7/25   |   cos Q = 24/25
ಕೋನ Q ಗೆ ಎದುರು ಬಾಹು = 7, ಪಕ್ಕದ ಬಾಹು = 24, ಕರ್ಣ = 25.

EXERCISE 8.1 · QUESTION 1

Find the Trigonometric Ratios

ತ್ರಿಕೋನಮಿತಿಯ ಅನುಪಾತಗಳನ್ನು ಕಂಡುಹಿಡಿಯಿರಿ
In ΔABC, right-angled at B, AB = 24 cm and BC = 7 cm. Determine:
(i) sin A, cos A     (ii) sin C, cos C
ΔABC ಯಲ್ಲಿ B ಲಂಬಕೋನವಾಗಿದ್ದು, AB = 24 cm ಮತ್ತು BC = 7 cm.

Step 1 — Understand the Triangle

B is the right angle. Therefore AC is the hypotenuse.

ಕರ್ಣ = AC
AC² = AB² + BC²
= 24² + 7²
= 576 + 49 = 625
AC = √625 = 25 cm

Step 2 — Calculate the Ratios

For angle A:
sin A = Opposite / Hypotenuse
= BC / AC = 7/25
cos A = Adjacent / Hypotenuse
= AB / AC = 24/25
For angle C:
sin C = Opposite / Hypotenuse
= AB / AC = 24/25
cos C = Adjacent / Hypotenuse
= BC / AC = 7/25
Remember: Opposite and adjacent sides change when the angle changes.
ಕೋನ ಬದಲಾದಾಗ ಎದುರು ಮತ್ತು ಪಕ್ಕದ ಬಾಹುಗಳು ಬದಲಾಗುತ್ತವೆ.
FINAL ANSWERS / ಅಂತಿಮ ಉತ್ತರಗಳು
sin A 7/25
cos A 24/25
sin C 24/25
cos C 7/25

EXERCISE 8.1 · QUESTION 3

Find cos A and tan A

cos A ಮತ್ತು tan A ಗಳನ್ನು ಕಂಡುಹಿಡಿಯಿರಿ
If sin A = 3/4, calculate cos A and tan A. sin A = 3/4 ಆದರೆ cos A ಮತ್ತು tan A ಗಳನ್ನು ಲೆಕ್ಕಹಾಕಿ.

STEP 1 — Given / ನೀಡಿರುವುದು

We know:
sin A = 3/4
Using the trigonometric identity:
sin² A + cos² A = 1

STEP 2 — Find cos A

(3/4)² + cos² A = 1
9/16 + cos² A = 1
cos² A = 7/16
cos A = √7/4
Since A is an acute angle, cos A is positive.

STEP 3 — Find tan A

We know:
tan A = sin A / cos A
tan A = (3/4) / (√7/4)
tan A = 3/√7
tan A = 3√7/7
FINAL ANSWERS / ಅಂತಿಮ ಉತ್ತರಗಳು
cos A = √7/4
tan A = 3√7/7
